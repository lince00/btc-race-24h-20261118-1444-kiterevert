KiteRevert: a mean-reversion trading bot for Coinbase Wrapped BTC (cbBTC) vs USDC on 1-minute bars. It buys early dips at half size (close 1.1% or more below SMA-120), adds a deep-drop recovery leg (3% or more drop in 120 bars), blocks entries in downtrends, and otherwise sits in cash. Built for the make.fun "Race a BTC trading bot live for 24 hours" bounty ($250 in USDC, paper money only — nothing is traded for real).

## Run it

```sh
node main.ts
```
